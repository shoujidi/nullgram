# 本地备注

入口：设置 → Null设置 → 伪装 → 名称与头像。

- 右上角加号统一选择联系人、机器人、群组或频道，编辑本地备注名及头像。可选用六个预设头像、随机预设或设备图片。保存后生效，返回不保存草稿；不上传头像。
- 在「名称与头像」页面直接搜索；已有「搜索本地备注」入口仍保留。该页面检索本机当前账号的全部备注，不受聊天最近活跃时间、归档状态或最近 600 个会话的限制，不向 Telegram 发送查询词。
- 管理页点按记录编辑名称和头像，长按可打开聊天或分别恢复原名、原头像；独立搜索入口仍保留点按打开聊天。主题切换及恢复外观不会清空这些设置。本机缺少对应聊天资料时不会按备注联网搜人，仍可以清除该备注。
- 普通 Telegram 搜索保留原名、用户名和消息搜索，不再匹配私人备注；普通搜索可能发送查询词到服务器。
- 云设置同步不导出备注，云端恢复也不会覆盖或新增本机备注。备注变动本身不会触发云自动同步。明确导出的本地设置文件仍包含备注，请自行保管。
- 本次修复不会自动删除此前已经上传的云备份。如曾使用旧版本同步过备注，可以在原有云设置界面管理旧备份。
- 未修改名字就点击完成，不会额外创建备注。将已有备注清空或使用恢复原名操作，可重新显示 Telegram 提供的名称。
- 系统通知中的聊天标题和发送者名称会按当前账号读取备注，即使尚未加载用户或群资料。消息原文本不会被按姓名进行全文替换。

此功能保留原有复读、提醒、普通通知渠道、图标选择和开屏设置。
